# FreeLab Coworking · site oficial

Site estático (HTML + CSS + JS, sem build) publicado na Vercel em https://www.freelabcoworking.com.br

## Como editar preços e horários
Abra `index.html`, procure por `EDITE AQUI` (no fim do arquivo) e altere os objetos `SPACES` (preços) e `HOURS` (horários).
`null` num preço mostra "Sob consulta" e o botão abre o WhatsApp.

## Reservas
Todos os botões "Reservar" apontam para https://freelab-coworking.reservio.com/

## Publicar
Cada `git push` na branch `main` publica automaticamente na Vercel.
